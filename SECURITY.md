# Security Policy

This repository contains open hardware documentation, CAD resources, firmware examples, and device integration notes.

## Reportable Issues

Please report security-sensitive or safety-sensitive problems privately when possible, including:

- Firmware examples that could expose credentials or private data.
- Hardware notes that could create unsafe power, charging, thermal, or battery behavior.
- Display or GPIO guidance that could damage hardware when followed as written.
- Repository files that accidentally include private material.

## How to Report

Use GitHub private security advisories if they are enabled for this repository. If they are not available, contact MindReset through the official support channels linked from:

https://dot.mindreset.tech

For ordinary documentation bugs, broken links, or non-sensitive hardware questions, open a public issue.

## Supported Versions

Only the latest public files on the default branch are actively maintained unless a device package explicitly documents versioned support.
