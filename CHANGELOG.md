# Changelog

All notable public releases of the Dot Open Platform repository are documented here.

## 2026-06-17

### Added

- Initial Quote/0 open hardware resource package.
- Quote/0 enclosure STEP file exported from Shapr3D in millimeter units.
- ESP32-C3 GPIO pinout in Markdown, CSV, and JSON formats.
- Minimal UC8251D 152 x 296 monochrome e-paper display driver for ESP-IDF.
- Display waveform/LUT documentation for the included UC8251D full-refresh flow.
- ESP-IDF minimal display example.
- Official online links for the Dot Developer Platform, Open APIs, Content Studio, Community Co-Creation, and Quote/0 docs.
- Repository license, notice, contribution, support, security, and GitHub issue templates.
