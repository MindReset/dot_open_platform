# Changelog

All notable public releases of the Dot Open Platform repository are documented here.

## 2026-08-19

### Added

- Rand/0 Display Mode capability package with a local WebSocket protocol reference and official browser example.

## 2026-07-29

### Added

- Two-part AdventureX 2026 badge enclosure for Quote/0 as binary STL files.

## 2026-06-17

### Added

- Initial Quote/0 open hardware resource package.
- Quote/0 enclosure STEP file exported from Shapr3D in millimeter units.
- ESP32-C3 GPIO pinout in Markdown, CSV, and JSON formats.
- Minimal UC8251D standard edition 152 x 296 monochrome e-paper display driver for ESP-IDF.
- Minimal UC8151/IL0324 Early Bird Edition 152 x 296 monochrome e-paper display driver for ESP-IDF.
- Display driver selection guidance based on the edition label shown in Dot. App device details.
- Display waveform/LUT documentation for the included full-refresh flows.
- ESP-IDF minimal display example.
- Official online links for the Dot Developer Platform, Open APIs, Content Studio, Community Co-Creation, and Quote/0 docs.
- Repository license, notice, contribution, support, security, and GitHub issue templates.
