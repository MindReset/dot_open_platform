# Read Pico Enclosure

Use the Read Pico enclosure model to design custom cases, mounts, and accessories.

## Included Files

| File | Format | Notes |
| --- | --- | --- |
| [read_0-enclosure.step](step/read_0-enclosure.step) | STEP AP242 | Read Pico enclosure, exported from Shapr3D in millimeter units; contains two solid bodies |

The source model was exported on `2026-09-17T18:39:30+08:00`. The STEP header identifies MindReset and Read Pico and includes the source URL and license identifier. These file-level markings do not add an embossed or engraved logo to the geometry.

## Usage Notes

- Open the STEP file in your CAD tool with millimeter units to inspect or modify the enclosure.
- Check dimensions, wall thickness, assembly clearances, display alignment, and access to ports and controls against your actual device before manufacturing.
- Confirm fit and tolerances for your chosen materials and process when designing cases, mounts, or other accessories.
- STEP is a CAD exchange format, not a native parametric source file. Rebuild editable features as needed in your CAD tool.
- No STL export, dimensioned drawing, or print profile is included. Export your modified design to a suitable format and verify its scale before printing or machining.
