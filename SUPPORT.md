# Support

Use GitHub issues for public questions about:

- Missing or unclear documentation.
- GPIO and display integration problems.
- Enclosure file issues.
- Example firmware bring-up problems.
- Manifest or repository structure problems.

When reporting a hardware or firmware issue, include:

- Device: `Quote/0`
- Hardware revision, if known
- Firmware framework and version, if relevant
- File path or documentation section involved
- Clear reproduction steps or photos/screenshots when useful

Do not post private credentials, API keys, unreleased supplier files, or private manufacturing documents.
