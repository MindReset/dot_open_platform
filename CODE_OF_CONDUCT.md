# Code of Conduct

This repository is for open hardware documentation, firmware examples, mechanical files, and integration notes around Dot devices.

We expect contributors to keep discussions technical, respectful, and useful for people building or modifying hardware. Do not use issues or pull requests for harassment, personal attacks, spam, or unrelated promotion.

Maintainers may edit, close, hide, or remove content that makes the project harder to use or review. Repeated abusive behavior may lead to blocking from the project.
